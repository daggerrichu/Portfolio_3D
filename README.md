# Lipin Kumar — Interactive 3D WebGL Portfolio Workspace

An immersive, interactive 3D WebGL portfolio workspace built for **Lipin Kumar (UI UX Designer & Game Developer)** using **Three.js**, **Vite**, **HTML5 Canvas**, and **Web Audio API**.

---

## ✨ Features

- **🌐 3D Interactive Room Environment**: Fully navigable 3D room with OrbitControls, procedural ceramic tile floor, custom gaming desk, PC tower, Xiaomi 4K monitor, gaming chair, and data center server rack.
- **🖼️ All-in-One 3D Wall Display Boards**:
  - **Back Wall Billboard**: High-resolution 2D Canvas rendering Lipin Kumar's shipped real-world projects (Talentshealth.com, ionaught.com, frontendwarfare.com, actonposh.com, Promptier, Medicine & Stock Management Apps, and Drowsiness Detection System) plus academic metrics.
  - **Left Wall Gallery Board**: Work Experience timeline (ALOKIN Software, IONAUGHT Technologies, Srishti Innovative & Keltron), Education (B.Tech CS, Vidya Academy), and Contact Details.
- **🎯 Clickable Props & Smooth Camera Zoom**: Click any wall display board or 3D room prop to smoothly animate the camera in front of that item.
- **🏠 Default View Home Button**: Fixed glassmorphic screen button to immediately reset the camera back to the optimal wide room perspective.
- **🔊 Zero-Latency Web Audio Engine**: Tactile mechanical UI click sound synthesis on every user interaction.
- **☀️ Real-Time Day / Night Lighting Modes**: Seamless environment light switching between bright daylight and dark cyberpunk room ambience.

---

## 🛠️ Tech Stack

- **Core**: JavaScript (ES6+), HTML5, Vanilla CSS
- **3D Engine**: Three.js (WebGL, OrbitControls, GLTFLoader, FBXLoader, EffectComposer)
- **Audio Engine**: Native Web Audio API (Synthesized Oscillators)
- **Build Tool**: Vite

---

## 🚀 Quick Start (Local Setup)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open `http://localhost:3001` in your web browser.

### 3. Build Production Bundle
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
